# AniRadar

AniRadar is a private anime tracker for one invite-only group of friends.

**Downloading it won't do anything for you unless you've been invited.** The app only opens with a one-time invite code that the group's admin makes for you. There's no sign-up, and each code works once, for one person.

## Invited?

1. Download **AniRadar-Setup.exe** from the [latest release](https://github.com/kiipism/aniradar-releases/releases/latest).
2. Run it. If Windows says *"Windows protected your PC"*, click **More info → Run anyway**.
3. Enter the code your admin sent you and choose your password.

After that, AniRadar keeps itself up to date.

## Not invited?

There's nothing to see without a code. Ask the person who runs your group for one.
